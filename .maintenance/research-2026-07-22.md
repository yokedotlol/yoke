## 1. Agent identity standards

**Core standards were quiet this week. No Yoke code change required from standards movement.**

| Spec | Current status | Change this week |
|------|----------------|------------------|
| DANCE client-auth | client-auth-12, IESG approved and Proposed Standard bound | No change |
| DANCE architecture | architecture-10, Revised I-D Needed | No change |
| DANCE tls-clientid | tls-clientid-07, waiting for AD go-ahead / Revised I-D Needed | No change |
| AIMS Framework | draft-klrc-aiagent-auth-03 | No change |
| Web Bot Auth | architecture-05 and registry-01 | No change |
| WIMSE cross-org delegation | draft-reece-wimse-cross-org-delegation-00 | No change |
| Groundmark | May 2026 I-Ds | No new revision found |
| BANDAID | Active draft | No new revision found |

The standards watchlist was updated separately with three peripheral drafts worth monitoring, but none are ready for Yoke detection:

- `draft-jiang-oauth-intent-admission-00`: binds an agent's declared intent to authorization decisions using WIMSE credentials.
- `draft-ietf-aipref-vocab`: AI preference vocabulary referenced by Web Bot Auth registry `purpose` metadata.
- `draft-narvaneni-agent-uri`: proposes `agent://` URIs for identifying agents and resources.

**Recommendation:** keep DANCE readiness detection on the near-term roadmap. DANCE client-auth is the only tracked item that looks close enough to RFC status to justify implementation planning.

## 3. Detection research

This week's useful research was practical rather than standards-driven: fill gaps in technology and consent-platform detection.

### CMS/site builder gaps

Two site builders had enough distinctive public markup and asset patterns to add low-risk fingerprints:

| Platform | Detection signals added | Why it matters |
|----------|-------------------------|----------------|
| Tilda | `meta generator` matching Tilda, `t-records` / `tilda-` classes, `tildacdn.com` script and CSS assets | Common hosted site builder. Distinctive CDN and markup make false positives unlikely. |
| Duda | `meta generator` matching Duda, `window._d_site`, `duda_` globals/classes, `multiscreensite.com`, `duda.co`, and `dmcdn.net` assets | Common agency/SMB site platform. Distinctive asset hosts and globals make detection straightforward. |

### Consent management gap

Klaro was added as a CMP pattern:

- Script signals: `klaro.js`, `klaro-no-css`, `kiprotect.com/klaro`, `klaro.org`, `heyklaro.com`
- HTML signals: `klaro--`, `klaro-modal`, standalone `klaro`

This brings the CMP pattern list to 25 entries.
